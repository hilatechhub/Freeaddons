💰 Cash Journal

Gestión Profesional de Caja para Odoo 19

Versión 19.0.1.0.0 • Odoo 19 • LGPL-3

📋 Acerca de Este Módulo

Cash Journal es una solución ERP completa y profesional para la gestión integrada del flujo de caja. Diseñado para funcionar perfectamente con Odoo, este módulo ofrece un flujo de trabajo intuitivo, informes detallados y trazabilidad financiera robusta.

Ya sea que gestione un restaurante, una tienda minorista o un negocio de servicios, Cash Journal simplifica el control de caja mientras asegura el cumplimiento normativo y la seguridad de datos.

✨ Características Principales

📊 Informes Mensuales

  • Numeración secuencial automática
  • Saldo inicial inteligente (heredado)
  • Cálculo automático del saldo final
  • Protección contra modificaciones

📝 Operaciones Diarias

  • Entradas y salidas simplemente firmadas
  • Descripción y beneficiario
  • Clasificación automática
  • Bloqueo después del cierre

🔄 Flujo de Trabajo Integrado

  • Abrir caja del día
  • Registrar operaciones
  • Cerrar caja del día
  • Cerrar informe mensual

📑 Operaciones Analíticas

  • Vista de lista completa de operaciones
  • Filtrado por tipo y estado
  • Análisis de gráficos de barras
  • Visualización total por informe

📊 Informes Profesionales

  • Exportación Excel con formato
  • Informe PDF profesional
  • Colores de marca de empresa
  • Resúmenes automáticos

🔒 Seguridad y Control

  • Dos roles de usuario
  • Permisos granulares
  • Registro de auditoría completo
  • Protección de datos

🔧 Detalles Técnicos

Modelos de Datos

Modelo Descripción Campos Clave
cash.journal.report Informe mensual de caja Número, Mes, Saldo Inicial/Final, Estado, Operaciones
cash.journal.operation Operación diaria Fecha, Descripción, Monto, Beneficiario, Bloqueo
cash.journal.pdf.report Asistente de informes (transitorio) Fecha Inicio, Fecha Fin, Empresa, Exportar
